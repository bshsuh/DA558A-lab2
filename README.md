# Personal Website Project 
A simple static website that implements HTML/CSS/JavaScript contact form.

## Setup

1. Clone or download the repository
2. Open `index.html` in a web browser

No build steps or dependencies are required.

## Files

- `index.html` – markup
- `external-page.html` – markup
- `global-sheet.css` – styling
- `index-sheet.css` – styling
- `external-page-sheet.css` – styling
- `contactform.js` – logic
- `images/` – image assets
